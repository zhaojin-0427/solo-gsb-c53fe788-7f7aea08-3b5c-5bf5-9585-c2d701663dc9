    现场地址核验

    选择任一已发布方案，上传现场 CSV（需含表头：灯具ID,线路,起始地址,通道数； 兼容本系统导出的地址表 CSV，多余列自动忽略）。服务端以所选方案发布时的落点为基准， 按灯具 ID 对齐并计算闭区间；坏行、非法线路、越过 512 通道或重复 ID 的行会被隔离并逐项列出， 且只要存在异常行整表结论就不会是“一致”。核验为只读操作，不修改编排与发布数据。

    DMX 信号回放

    选择一份已发布方案，上传信号 CSV（UTF-8，需含表头：时间(毫秒),线路,通道,值； 时间为非负毫秒、线路 1-4、通道 1-512、值 0-255），每行更新一个槽位。 服务端从所选版本的发布快照恢复灯具闭区间与保留区，按时间重建帧： 同一毫秒的多行合为一帧，槽位初值为 0，未更新的值延续上一帧。 页面按灯具展示相对通道读数及变化；有快照时逐帧列出保留区与未分配通道的非零值 （旧发布记录无快照时，灯具外非零值继续显示但归属未知，不会用当前保留区反推）。 同一毫秒同槽出现不同值时，可选择整表拒收或按文件顺序取末值（结果中逐项标注）。 回放为只读操作，不修改编排数据。
